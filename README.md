Este projeto é uma plataforma inspirada no Airbnb, desenvolvida com o framework Spring Boot. Seu propósito é criar um sistema completo para gerenciar locações de propriedades, permitindo que anfitriões (hosts) anunciem suas acomodações, enquanto hóspedes (guests) podem buscar, reservar e avaliar os locais disponíveis.

O sistema é projetado para ser funcional e escalável, com foco em uma arquitetura robusta e amigável para os usuários. Ele visa simplificar o processo de hospedagem e reserva, proporcionando um ambiente digital confiável para ambos os lados.

---

## Propósito 📝

- Facilitar o gerenciamento de usuários, propriedades e reservas.
- Oferecer uma experiência intuitiva de busca e filtro de acomodações.
- Automatizar tarefas como autenticação, cadastro e edição de informações.
- Proporcionar um sistema de feedback para melhorar a qualidade das acomodações.

---

## Funcionalidades ✨

1.Gerenciamento de Usuários:

- Cadastro, edição e exclusão de usuários.
- Busca avançada por nome, e-mail ou telefone.
  
2.Gestão de Propriedades (Places):

- Cadastro, edição e exclusão de propriedades.
- Busca por estado, cidade e país.
- Filtro por faixa de preço e capacidade.

3.Reserva de Acomodações (PlaceToBook):

- Registro de locais disponíveis para reserva.
- Ordenação por preço (crescente ou decrescente).
- Busca personalizada por número de quartos, banheiros, cozinhas e salas.

4.Avaliações (Reviews):

- Cadastro e gerenciamento de avaliações feitas por hóspedes.
- Edição e exclusão de avaliações.

5.Sistema de Reservas (Booking):

- Gerenciamento completo de reservas.
- Exibição de relatórios consolidados.

6.Autenticação e Login:

- Tela de login e autenticação com validação de credenciais.

7.Dashboard de Hospedagem:

- Ferramentas para anfitriões gerenciarem a disponibilidade de suas propriedades.
